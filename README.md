# Smart Waste Classification System

## Project Overview

This project is an end-to-end Deep Learning Computer Vision application that classifies waste images into different categories using Convolutional Neural Networks (CNNs) and Transfer Learning.

The project is being developed as part of an internship to learn the complete machine learning development lifecycle—from data collection to cloud deployment.

---

## Objectives

- Build a waste image classification model.
- Compare multiple deep learning models.
- Explain predictions using Grad-CAM.
- Develop a FastAPI backend.
- Create a Streamlit web application.
- Deploy the application using Docker and the cloud.
