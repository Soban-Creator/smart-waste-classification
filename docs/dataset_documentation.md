# TrashNet Dataset Documentation

## Dataset Name

TrashNet

## Project Use

TrashNet is used to train and evaluate a deep learning model that classifies
a single dominant waste object into one of six categories.

## Dataset Source

Original TrashNet GitHub repository by Gary Thung and Mindy Yang.

## Classes

1. Cardboard
2. Glass
3. Metal
4. Paper
5. Plastic
6. Trash
